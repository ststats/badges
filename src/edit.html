편집 비밀번호

저장할 때 쓰는 비밀번호예요(Vercel 환경 변수 EDIT_PASSWORD). 한 번 넣으면 이 브라우저에 기억돼요.

SOOP 쿠키 바꾸기(즐겨찾기 글용)
  1. PC 크롬에서 SOOP에 로그인한 채로 소주양 게시판을 열기
  2. F12 → Network → 새로고침 → 이름에 board가 들어간 요청 → Headers → Request Headers의 cookie 값 전체 복사
  3. 아래에 붙여 넣고 저장(위 편집 비밀번호를 씁니다)

저장하면 서버가 SOOP에서 먹히는지 먼저 확인하고, 암호화해서 저장소에 올립니다(저장소에는 암호문만). 1~2분 뒤 적용돼요.
